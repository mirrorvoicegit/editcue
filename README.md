# EditCue｜逐字稿工作台

團隊使用的後製需求標示工具，獨立於 `podcast-datas-platform`。

- 匯入 SRT、VTT、Word、PPTX、PDF、圖片及 `.editcue.json` 工作檔
- 選取逐字稿標示剪掉、精彩片段、短影音、圖卡／字卡及特殊需求
- 短影音範圍僅使用紅色台詞；圖卡／字卡使用統一黃色底色
- 重疊指令以不同文字標籤呈現，圖卡連續時以虛線分隔
- 匯出保留原始段落的 Word 與已編號圖片 ZIP

資料僅在瀏覽器處理，不會因為匯入而上傳至 GitHub。請定期下載 `.editcue.json` 備份工作進度。

**網址**：https://mirrorvoicegit.github.io/editcue/

PPTX、PDF 轉圖可能受到字型、圖表或瀏覽器支援影響，正式交給剪輯師前需檢查各頁圖片。
