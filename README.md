# EditCue｜逐字稿工作台

團隊使用的後製需求標示工具，獨立於 `podcast-datas-platform`。

- 匯入 SRT、VTT、Word、PPTX、PDF、圖片及 `.editcue.json` 工作檔
- 選取逐字稿標示剪掉、精彩片段、短影音、圖卡／字卡及特殊需求
- 精彩片段以鮮黃色底（#FFEB00）配深色文字標示；圖卡／圖片範圍以薄荷綠底（#B8F0D2）配深色文字標示
- 插入字卡使用正藍色文字（#0054C8）；短影音使用紅色文字；剪掉維持灰底及刪除線
- 圖卡與精彩片段重疊時，以黃底及薄荷綠側邊提示共同呈現；Word 匯出也保留兩種標記，圖卡連續時以虛線分隔
- 匯出保留原始段落的 Word 與已編號圖片 ZIP

資料僅在瀏覽器處理，不會因為匯入而上傳至 GitHub。請定期下載 `.editcue.json` 備份工作進度。

**網址**：https://mirrorvoicegit.github.io/editcue/

PPTX、PDF 轉圖可能受到字型、圖表或瀏覽器支援影響，正式交給剪輯師前需檢查各頁圖片。
## 最新更新（v6.6）

- 重新整理瀏覽器後，恢復離開前停留的「逐字稿／初剪核對」頁面，不再一律跳回逐字稿。
- 核對勾選狀態、全部／未核對、類型篩選、搜尋文字、已展開的指示與清單捲動位置都會一併記住。
- 核對變更即刻備份於同一瀏覽器的本機儲存；原有 IndexedDB 自動草稿仍保留。下載的 `.editcue.json` 亦含核對頁設定。
- 核對紀錄會核對目前載入的逐字稿識別，避免誤套用到另一份素材；清空工作區時同步清除本機核對紀錄。
- 本機記憶不會跨瀏覽器／裝置同步，無痕模式、清除網站資料或阻擋網站儲存可能使紀錄無法保留；正式交接仍建議儲存 JSON 工作檔。

## 最新更新（v6.5）

- 「初剪核對」頁中的「剪掉」項目，改以剪接後保留的前後文為主要核對資訊，而不再以被刪除片段的頭尾台詞為重點。
- 同一張灰色項目會顯示剪掉字幕範圍與原始時間，以及「保留前文 → 接續後文」兩段文字；同時顯示對應的字幕編號範圍。
- 前後文最多各取 8 則保留字幕，跳過其他已標示剪掉的字幕；位於素材開頭或結尾時會顯示相對應狀態。
- 前後保留文字或相鄰的剪掉範圍改變時，相關項目會自動恢復為未核對。原本的打勾、搜尋、圖卡顏色及其他標示不變。

## 最新更新（v6.3）

- 初剪核對清單將「精彩片段」集中放在最前面，配合成片開頭的核對流程；其餘指示仍依原始字幕順序排列。
- 新增核對區搜尋欄，可搜尋字幕編號（包含標記範圍中間的字幕）、原始時間碼、台詞內容、圖卡名稱及處理說明。
- 新增後製類型篩選：全部類型、精彩片段、剪掉、插入圖卡、插入字卡、短影音、其他需求；可搭配「全部／未核對」使用。
- 精彩片段旁顯示「片頭」，並標註所顯示的起迄時間是原始素材位置，不是初剪成片時間；未嘗試自動推算剪輯後時間碼。
- 保留既有背景色、核對勾選、本機工作檔進度及點文字／圖片放大功能。

## 最新更新（v6.2）

- 初剪核對清單加大字體：標題 16px、字幕編號及時間碼 14px、台詞摘要 14px、處理說明 15px；單則展開後再加大。
- 每則核對項目新增「放大／收合」按鈕，在原清單直接展開完整台詞與更大的指示文字，不改動核對狀態。
- 圖卡縮圖加大至約 145 × 94px，點擊「點圖放大」開啟既有原始圖片預覽；點圖與放大文字均不會觸發勾選。
- 修正核對模式下按 Esc 無法關閉圖片預覽的問題。
- 放大狀態僅供當次瀏覽，勾選仍儲存在本機草稿及 JSON 工作檔。

## 最新更新（v6.1）

- 初剪核對頁為不同類型指示使用整張項目背景色：剪掉灰、圖卡薄荷綠、字卡淺藍、精彩片段黃、短影音淺紅、特殊需求淺紫；其他備註、移位另有辨識色。
- 每項明確顯示「起點／終點」，分別包含字幕編號、起訖時間碼及台詞摘要。即使只標一則字幕，也會顯示完整起訖時間。
- 手動文字註記只顯示插入「位置」，避免誤標為一個不存在的片段範圍。
- 保留原本的勾選、全部／未核對切換及本機工作檔進度保存；針對右側窄視窗調整換行和版面。

## 最新更新（v6.0）

- 左側工具列新增「核對」，進入獨立的「初剪核對」頁面，適合與 Frame.io 左右並排。
- 清單只呈現原先建立的後製標示與文字註記，依字幕順序排列；每項可勾選核對完成，並可切換「全部／未核對」。
- 顯示字幕範圍、時間碼、製作人備註；指定圖片時提供縮圖，不需要逐頁翻查完整逐字稿。
- 勾選進度儲存在瀏覽器本機草稿與 `.editcue.json` 工作檔（含後製 ZIP 內的工作檔）；若修改原標示，該項自動恢復未核對。舊工作檔可直接使用，預設全部未核對。
- 修正原 Word 匯出分支將來源類型意外賦值的判斷式，避免對後續原始字幕資訊造成影響。

## 最新更新（v5.9）

- 匯出的 Word 每則後製指示結尾新增「下一個」內部連結，直接跳到下一則處理位置（剪掉、圖卡、精彩片段、字卡、短影音、特殊需求及手動文字註記都會依文件順序串接）。
- 不新增目錄頁、不變更逐字稿的字幕順序或標示配色；最後一則不顯示無效的「下一個」連結。
- 桌面版 Word 預設使用 Ctrl＋點擊開啟連結；若要單擊跳轉，可到「檔案 → 選項 → 進階」取消「使用 CTRL＋滑鼠左鍵追蹤超連結」。

## 最新更新（v5.8）

- Word 後製指示改成每則一行，例如「■ 插入圖卡｜圖卡_001.png｜字幕 141–227」，不重複顯示字幕起點和時間碼。
- Word 指示採用較大的粗體字及完整段落底色；字幕範圍中的編號、時間碼、台詞與間隔空白一併著色，讓範圍連成醒目的區塊（跨頁仍會分頁）。
- 後製 ZIP 新增 `原始字幕/`，保留最初匯入的 SRT、VTT、TXT 或 DOCX；文字型新匯入檔盡可能按原始位元組備份。
- 同一個起點有兩種以上需求時，各自以獨立的單行標示，避免後製交付文件漏掉其中一項。

- 調整精彩片段、圖卡與字卡顏色，並同步網站、標記預覽與 Word 匯出格式。
- 桌面版可直接拖曳多個字幕段落，使用黑白區間線條，不再出現原生藍色文字反白。
- 搜尋面板新增上一處、下一處、單筆取代及全部取代。
- 取代僅修改台詞，不影響原始字幕編號與時間碼；支援復原及重做。
- 已測試 896 段 SRT 的搜尋取代，並驗證 DOCX 輸出。
